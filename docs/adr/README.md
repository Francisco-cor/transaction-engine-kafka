# Architecture Decision Records

Los ADRs registran decisiones que afectan las garantías del sistema. Un ADR nuevo debe incluir contexto, decisión, alternativas descartadas y consecuencias. No se reescribe una decisión histórica: se crea otro ADR que la sustituye y enlaza el anterior.
